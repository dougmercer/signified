    Library comparison¶

    Signified works much like the signals in many JavaScript frameworks: a calculation follows the values it reads, recalculates only when needed, and effects handle actions. This page shows how it lines up with other libraries, so you can tell what carries over when moving code or ideas between them.

    Python libraries¶

    In each row, x starts at 1 and doubled calculates twice its value. Imports are omitted.

    Library Create Read / write Calculate
    Signified x = Signal(1) x.value / x.value = 2 doubled = x * 2
    reaktiv x = signal(1) x() / x.set(2) doubled = computed(lambda: x() * 2)
    Param x = rx(1) x.rx.value / x.rx.value = 2 doubled = x * 2

    reaktiv is the closest match. Like Signified, it follows the values a function reads, caches results until an input changes, and runs effects immediately. It reads by calling x() instead of using operators, compares every value with is, prints effect errors instead of raising them, and offers async helpers and locking for graphs shared across threads.

    Param builds reactive expressions differently: rx records the operations you apply and the values you pass in, rather than following reads inside a function. Its watchers subscribe to named parameters. If you already use Param parameters, its expressions connect directly to that model.

    JavaScript libraries¶

    Library Create / read Write Calculate
    Angular const x = signal(1) / x() x.set(v) computed(() => x() * 2)
    Vue const x = ref(1) / x.value x.value = v computed(() => x.value * 2)
    Svelte 5 let x = $state(1) / x x = v let y = $derived(x * 2)
    Preact Signals const x = signal(1) / x.value x.value = v computed(() => x.value * 2)
    Solid const [x, setX] = createSignal(1) / x() setX(v) createMemo(() => x() * 2)
    MobX const x = observable.box(1) / x.get() runInAction(() => x.set(v)) computed(() => x.get() * 2)

    All of these follow the values a calculation reads, as Signified does. The frameworks also schedule effects around rendering, which standalone Python code does not need.

    Library Calculation runs Counts as unchanged Custom equality Tracks changes inside objects
    Signified When read Same built-in scalar value, otherwise same object ✓ No*
    reaktiv When read Same object (is) ✓ No
    Param rx When read* Inputs only, by parameter comparison — No
    Angular When read Object.is ✓ No
    Vue When read Object.is ✗ Yes (shallowRef opts out)
    Svelte 5 When read === ✗ Yes ($state.raw opts out)
    Preact When read === ✗ No
    Solid On creation and on each change === ✓ No (createStore opts in)
    MobX When read; cached only while observed Object.is ✓ Yes (observable.ref opts out)
    • Signified: signal[key] = value and signal.attr = value notify, but changes made through .value need update().
    • Param: building or inspecting an rx pipeline can run some steps early. Param does not compare results, so an unchanged result still notifies.

    "Counts as unchanged" decides whether anything downstream updates. In every library above except Param, a calculation that recalculates to an unchanged result stops the update there.

    Effects¶

    "Immediately" means before the write that triggered it returns, or when the surrounding batch ends.

    Signified Effect Immediately Immediately batch() You call dispose() or drop the reference

    Param watchers After the first change Immediately batch_call_watchers You call unwatch

    • Angular: effects created outside a component run as a microtask instead.
    • Vue's watch, MobX's reaction, and Param's watchers wait for a change before their first run. Several frameworks offer options to change timing.

    Where Signified differs¶

    • Equality. Built-in scalars such as int, float, and str compare by value; everything else compares by identity, and Signified never calls an object's __eq__ unless you pass equal=. reaktiv uses is everywhere, and the JavaScript libraries use === or Object.is.
    • Nested reactive values stay as they are. A signal holding another signal returns that signal, not its value. Read it with unref, deep_unref, or a Binding. Vue, by contrast, unwraps refs inside reactive objects for you.
    • Binding. A binding is one stable handle whose source you can swap. Angular's linkedSignal, Svelte's writable $derived, and Vue and MobX computed setters solve related problems, but each writes or overrides values rather than switching sources.
    • Operators. Like Param, Python operators build calculations, so price * quantity is already reactive.
    • Errors. A failed calculation saves its exception and raises it on each read until an input changes. When effects fail, the rest still run and the errors are raised together. reaktiv and MobX log effect errors instead, and Vue, Svelte, and Solid send them to framework error handlers.
    • Synchronous, one thread at a time. Reads are tracked only while a function runs, never across await. Separate graphs can run on separate threads, but each graph is used from one thread at a time.

    If you need every event in order, rather than the latest value, an event-stream library such as ReactiveX for Python is a better fit. Signals can skip intermediate values that nothing read.
