# mypyc experiment

Status: parked on 2026-10-09. Revisit when mypyc supports weakrefs on native
classes ([mypyc/mypyc#1102](https://github.com/mypyc/mypyc/issues/1102)).
Branch `mypyc-experiment`, based on `77bb4c6`. Numbers are from darwin arm64.
The suite uses CPython 3.14.3; key3d uses its own 3.12.12 venv.

## Verdict

Compiling the engine with mypyc roughly halves signified's own overhead.
Shipping it needs a patched mypyc, because stock mypyc 2.4.0 cannot weakly
reference native instances on Python 3.12+.

## Results

`tests/test_benchmarks.py` ran under a timeit stand-in for `benchmark`
(`benchmarks/mypyc/bench_suite.py`). Times are the best of 7.

| build | geomean vs baseline | range |
| --- | ---: | ---: |
| A: patched mypyc, native classes | **1.94x** | 0.85x (`deep_unref_dict`) to 2.57x |
| A without `allow_interpreted_subclasses` | 1.94x | same |
| B: stock mypyc, public classes `native_class=False` | 1.13x | 0.72x to 1.40x |
| A's source, uncompiled | 0.90x | `_mixin.__setattr__` sees internal writes |

key3d `moving` scene (400 animated objects), `benchmarks/mypyc/key3d_ab.py`:

| | baseline | A |
| --- | ---: | ---: |
| graph pass (set frame, read 400 matrices) | 14.1 ms | 9.9 ms |
| full frame (render + readback) | 45-46 ms | 39-40 ms |

In the graph pass, about 5.5 ms is key3d's own `@computed` bodies, which
neither build changes.

Per-node bookkeeping (`benchmarks/mypyc/bench_fusion.py`, chain of operator
Computeds, write then read):

| | baseline | A |
| --- | ---: | ---: |
| per extra node | 1.2-1.9 us | 0.70-0.87 us |
| write + read, one node | 2.0 us | 1.1 us |
| 500 leaves of `(t - a) * b + c`, per frame | 2.39 ms | 1.21 ms |

Plain Python does that frame in 20 us.

## What it took

- **Attribute types.** Slot attributes needed class-level annotations, or mypy
  resolves them through the mixin's `__getattr__`. `Variable.__init__` needed
  `-> None`: an untyped `__init__` crashes mypyc's self-leak analysis.
- **Weakrefs.** mypyc emits `__weakref__` support only for native classes with
  a Python base. Even then, on 3.12+ it sets `Py_TPFLAGS_MANAGED_DICT` without
  `Py_TPFLAGS_MANAGED_WEAKREF`, and dealloc never calls
  `PyObject_ClearWeakRefs`. `mypyc-weakref.patch` adds both. This is the
  workaround #1102 describes as segfault-prone, made safe, not the planned
  opt-in `@mypyc_attr(weakrefs=True)` design.
- **The mixin stays interpreted.** A native class with a Python base cannot
  define `__getattr__` or `__setattr__`. So `_ReactiveMixIn` is the uncompiled
  Python base, and `Signal`'s write forwarding moved into it behind
  `_FORWARDS_ATTRIBUTE_WRITES`. `Effect` and `_ObserverLinks` get weakrefs from
  `_weakbase.WeakrefBase`.
- **Direct writes.** Internal `object.__setattr__` writes became direct
  attribute writes, which compile to struct stores. That is why the uncompiled
  fallback is about 10% slower.
- **ABC dropped.** `Variable` no longer derives from `ABC`, since a native
  class cannot also take that base.
- **Binding type changes.** `Binding._impl` lost its narrowed annotation:
  mypyc rejects covariant attribute overrides. `Binding.value` became an
  explicit property, because `@Computed.value.setter` is not supported.
- **`derive()` error message.** mypyc checks typed call results at runtime, so
  `derive()` calls `build` through `Callable[[Any], object]` to keep its own
  error message.
- **Descriptor.** `_TrackedField` is `native_class=False`. Compiled, it stops
  acting as a data descriptor.
- **Subclassing.** The public classes allow interpreted subclasses, which
  costs nothing measurable.

Variant B (stock mypyc) also hit an internal crash on the closure in
`_ObserverLinks.add`. Property setters are unsupported on non-native classes.
`Signal[int]` fails at runtime ("is not a generic class"). Python subclasses
of non-native classes also fail mypyc's runtime type checks.

## Checks

- All 338 tests in `tests/` pass compiled, on 3.14 and on 3.12.
- Uncompiled, 406 tests and doctests pass. That is one fewer than baseline:
  the removed `Signal.__setattr__` docstring example.
- pyright reports 0 errors, same as baseline. That covers
  `tests/type_inference.py`.
- mypy reports 741 errors in `tests/type_inference.py`, against 744 at
  baseline. That file targets pyright, and mypy compliance was never there.
  mypyc only needs `src/` to pass with the `[tool.mypy]` codes disabled.

## Reproduce

```sh
uv sync --all-groups
uv pip install --python .venv/bin/python --no-binary mypy mypy setuptools
patch -d "$(.venv/bin/python -c 'import mypyc.codegen, os; print(os.path.dirname(mypyc.codegen.__file__))')" < mypyc-weakref.patch
./build_mypyc.sh
.venv/bin/python -m pytest tests -o addopts=""   # doctests can't be collected from compiled modules
.venv/bin/python benchmarks/mypyc/bench_suite.py tests/test_benchmarks.py > mypyc.json
```

For a baseline, export the parent commit's `src` and put it first on
`PYTHONPATH`. For key3d, build with key3d's interpreter (cp312). Then run
`key3d_ab.py` from the key3d root, with this `src` and a directory holding
`mypy_extensions.py` on `PYTHONPATH`.
